### ✅ Hospital Queue

Priority queue simulation using object-oriented programming.

Features:

* Patient registration
* Priority-based insertion
* Queue visualization
* Call the next patient
* View the next patient in the queue

Priority rules:

* 🔴 **Red**: Highest priority.
* 🟡 **Yellow**: Can move ahead of up to two green-priority patients.
* 🟢 **Green**: Regular priority.
* ⚫ **Black**: Added to the end of the queue.
